Privacy notice

This notice covers this website. What the Keyhole plugin itself does with your data is described in the README’s privacy section.

Who is responsible

Hosting

This website is hosted on GitHub Pages, a service of GitHub, Inc. (USA). When you open a page, your browser sends a request to GitHub’s servers. GitHub processes your IP address and the usual request data (such as the page requested, time, browser) to deliver the page and keep the service secure. According to GitHub, the IP address of every visitor of a GitHub Pages site is logged and stored for security purposes, whether or not the visitor is signed in to GitHub. See GitHub Pages: data collection and the GitHub General Privacy Statement.

The legal basis is the legitimate interest in delivering this website securely (Art. 6(1)(f) GDPR). The operator of this website has no access to these server logs.

What this website does not do

  • It sets no cookies and uses no local storage.
  • It uses no analytics, no tracking and no advertising.
  • It loads nothing from third parties: no external fonts, scripts, images or CDNs. Everything comes from this website.

Links to other websites

This website links to the Obsidian community directory, GitHub, GitHub Sponsors, Ko-fi and Buy Me a Coffee. Nothing is sent to them until you follow a link; from then on, their own privacy policies apply.

Your rights

Under the GDPR you have the right to access, rectification, erasure, restriction of processing and objection, and the right to lodge a complaint with a data protection supervisory authority. Since the operator of this website holds no personal data about its visitors, requests about the server logs are best directed to GitHub.
