# Security

Keyhole exists to keep files private, so security reports are very welcome.

Please report vulnerabilities privately via GitHub's "Report a vulnerability" (Security tab), not in public issues.

In scope: credential leaks (into notes, logs, URLs, synced files), unauthenticated access to stored files, path traversal, script execution from served files.

The Keyhole server has its own repository and security policy: https://github.com/dbraendle/keyhole-server
